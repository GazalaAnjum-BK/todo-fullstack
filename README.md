# 📝 Full Stack Todo Application

A full-stack Todo application built using **React, Node.js, Express, and MongoDB**.  
This project demonstrates complete CRUD operations with a modern UI, dark mode support, and real-time database integration.

---

## 🚀 Features

- ➕ Add new tasks  
- ✏️ Edit existing tasks  
- ☑️ Mark tasks as completed  
- 🗑️ Delete tasks  
- 🌙 Dark mode toggle  
- 📋 Table-based task display  
- 🔄 Real-time updates with MongoDB  

---

## ▶️ How to Run the Project Locally

### 1️⃣ Clone the Repository
git clone https://github.com/GazalaAnjum-BK/todo-fullstack.git

### 2️⃣ Run Backend
cd todo-app
npm install
node server.js

Backend will run on:
http://localhost:5000
